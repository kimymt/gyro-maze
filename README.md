# GYRO

指で世界を回し、球をゴールへ運ぶ3D自然素材の立体迷路。端末を傾ける操作も選べる。日本語、大型化する12ステージ、落下なし、端末内記録、オフラインPWA。

## 開発

Node.js 22.12以上。

```sh
npm ci
npm run dev
```

本番ビルドとオフライン検証:

```sh
npm run build
npm run preview -- --port 4173
```

Macで http://localhost:4173 を開く。通常の開発サーバーではService Workerを登録しない。本番プレビューで登録・全素材保存を検証する。同一ポートに別アプリのService Workerが残っている場合は、別ポートまたは新しいブラウザプロファイルを使う。

iPhoneのPWA試験はHTTPS配信元で行う。同じWi-FiのMacのHTTP IPアドレスだけではオフライン機能を試験できない。

## 操作

- 配色はシステムのライト／ダーク設定に自動追従。起動中の設定変更も反映する。
- ワールドは番号で選ぶ。冒頭の見出しとワールド名は画面に表示しない。
- ステージ一覧は2列で表示する。スマートフォンと幅980px以下のタブレットでは3D表示の下にステージ選択を配置する。操作ボタンは44px以上、ヘルプ本文は16pxで表示する。
- iPhone / iPadのSafariでは、保存完了後の選択画面に「オフラインで遊ぶ」の案内を表示する。「ホーム画面に追加する方法を見る」から共有メニューの手順を確認できる。閉じると7日間非表示。遊び方から手動で再表示でき、ゲーム中とホーム画面からの起動時は通知しない。

- ドラッグ: 360度回転。2本指のひねり: 画面軸で回転。ピンチ: ズーム。
- 起動時は毎回「指で操作」。選択画面か一時停止中に「端末を傾ける」を選び、端末の動きへのアクセスを許可すると傾き操作を使える。許可拒否・未対応・初回取得失敗時は指操作を維持する。
- 傾き操作は開始・再開時の持ち方が基準。端末を傾けると迷路も傾き、元に戻すと迷路も戻る。「基準合わせ」は現在の球と迷路の位置を保ったまま持ち方だけを再設定する。
- 傾き操作中もドラッグ・ピンチを使える。指で操作している間は端末入力を抑制し、指を離した持ち方から再開する。
- 傾き操作では縦横の変更、センサーの停止、背景移動時に一時停止する。再開ボタンで持ち方を取り直す。選択画面の待機中、ポーズ、ヘルプ、結果画面ではセンサー購読を停止する。
- デスクトップ: ドラッグ、ホイール、矢印キー、Q/E。
- 金色の中継点を順に通り、緑のゴールで球を止める。
- 球は裏返しても常に床に接し、見えない側面・端の境界でコース内に保つ。視点リセットのみ球を中継点へ戻す。
- 「球に寄る」またはピンチで、球を中心に拡大。04〜12は地形の大きさに合わせて拡大率・最大ズームを増やし、内部では地形を透視表示する。
- 最速のクリア記録を保存。途中の走行は保存しない。旧ステージの記録は新ステージへ引き継がず、画質設定は維持する。
- v0.3.0のステージ03は、終盤の大きな上りを低い通路と水平なゴールへ変更。旧03の記録は端末内に残し、新03のBESTとは分ける。01・02のコースと記録は継続する。

## 構成

- `src/levels.ts`: 12ステージの軽量な定義一覧と、選択時に生成・再利用する地形と通路。起動時に全ステージを生成しない。
- `src/physics.ts`: Rapier、120Hz重力積分、継ぎ目のない床と見えない通路境界。球の速度を制限し、毎ステップ境界内に収める。
- `src/scene.ts`: Three.js、材質、手前の遮蔽部材の透過、画質。
- `src/input.ts`: Pointer Events、多点入力、ズーム、キーボード。
- `src/tilt-permission.ts`, `src/tilt.ts`: 同じクリック内での許可要求、遅延読み込み、傾きの平滑化と上限、基準合わせ、センサー監視。
- `src/state.ts`: 進行・完了判定・保存検証。
- `src/main.ts`: 画面、ゲームループ、バックグラウンド停止。
- `src/install-guide.ts`: Safari向け追加案内の対象判定と表示抑制。端末内だけに保存する。
- `src/offline.ts`, `src/sw.template.js`, `scripts/build-sw.mjs`: 全素材キャッシュ、修復、更新。

初回起動では3Dの組み立て中に物理エンジンを取得し、エンジン準備完了時の3D再生成を省く。取得中も遊び方を開け、取得失敗時は再読み込みからやり直せる。実機の起動時間は `DEVICE_TESTS.md` の手順で測定する。

指操作の起動はセンサー許可・初回データ・傾きモジュールの実行を待たない。傾きモジュールも全素材キャッシュに含めるため、保存完了後なら未使用の傾き操作をオフラインで初めて選べる。初回の保存通信量はモジュール追加分だけ増える。

RapierのWASMはcompatパッケージ内に埋め込まれ、JavaScriptと一緒に配信・キャッシュされる。環境照明と3D形状はコードで生成し、外部モデル・フォント・画像サービスは使わない。

## テスト

```sh
npm test
npx playwright install chromium
npm run build
npm run test:e2e
```

物理テストは球をテレポートさせず、重力方向だけを変えて全ステージの通路を走破する。合成端末入力からカメラ変換・物理まで通す全12コースのゴール停止も検証する。自動制御は指操作の難易度やiPhone性能の保証ではない。実機チェックは `DEVICE_TESTS.md` に記録する。

公開URL: https://gyro-maze.kei1127miyamoto.workers.dev

静的配信の説明: https://developers.cloudflare.com/workers/static-assets/

Safariで配信URLを開き、共有メニューからホーム画面に追加。追加したアプリで「オフラインで遊べます」を確認してから機内モードを試す。iOSがサイトデータを削除した場合は再取得する。

更新版は選択画面の「更新する」で適用する。旧タブの遅延読み込みを壊さないよう旧版キャッシュを保持するため、更新ごとに保存容量が増える。初版では自動で旧キャッシュを消去しない。

## 07〜12の解放（v0.7.0）

01〜06は無料。SNSへのシェア、任意の募金箱・団体への寄付、開発者へのLightning送金のどれか一つで07〜12をまとめて解放する。すべて実施後の自己申告。共有画面を開く・リンクや送金先をコピーする・QRを表示するだけでは解放しない。

Lightningの送金先は `garbledaction736@walletofsatoshi.com`、金額は1 sat以上の任意額。送金先をコピーするかQR・ウォレットへのリンクを利用し、利用者のウォレットから直接送金する。GYROは請求書を発行せず、送金の成否を照会せず、サーバーに送金記録を保存しない。ウォレット・受取サービスが扱う送金記録とは別の範囲。

送金後は「送金しました」で解放。旧版で送金済みの利用者も再送金せず申告できる。入金通知・Preimage・復元コードは不要。

- `src/access.ts`: 端末内の解放と共通開始判定。BESTとは別に保存し、旧版の請求書と復元用情報を起動時に削除する。
- `src/unlock.ts`: 3種類の自己申告、送金先表示・コピー・QR。画面を開いた時だけ読み込む。

解放状態はこのブラウザだけに保存。別端末やサイトデータ削除後は、追加送金せず再申告する。保存不可の環境ではセッション中だけ有効と表示する。Safariとホーム画面アプリ間での保存共有は保証しない。

支援の申告と解放に通信は不要。QRのモジュールもオフライン保存に含む。実際の送金はウォレット側の通信が必要。旧版の自動確認処理・決済用ライブラリ・サーバーコード・KVバインドを撤去した。
